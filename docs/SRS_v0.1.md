# 소프트웨어 요구사항 명세서(SRS) v0.1

## 1. 문서 목적과 범위

교내 분실물 관리 서비스의 초기 요구사항을 정리한다. 본 버전은 가상 데이터를 전제로 하며, 실제 개인정보 처리와 학교 인증 연동은 범위에서 제외한다. 사진 기반 유사 물품 검색, 사진 매칭 자동 알림, 개인 휴대전화 번호 공개도 제외한다.

## 2. 기능 요구사항

|ID|기능 요구사항|상세/수용 기준|근거|우선순위|
|---|---|---|---|---|
|FR_00|분실물 보관 여부 조회|사용자는 등록된 분실물의 보관 여부를 조회할 수 있어야 한다. 조회 결과는 보관 중인 물품과 인도 완료 물품을 구분해 표시해야 한다.|NEEDS_1, NEEDS_3|높음|
|FR_01|분실물 보관 위치 조회|조회 결과에는 물품이 보관된 위치를 표시해야 한다. 단, 공개 가능한 위치 표현 방식은 정책으로 결정한다.|NEEDS_1, SC1|높음|
|FR_02|습득물 정보 등록|습득 학생은 자신이 습득한 물품을 앱에서 직접 등록할 수 있어야 하며, 행정 담당자는 분실물 센터로 접수된 습득 물품을 등록할 수 있어야 한다. 두 등록 경로에서 조회에 필요한 물품 정보를 등록하며, 필수 입력 항목은 정책으로 관리한다.|NEEDS_2, SC2, 확정 사항|높음|
|FR_03|분실물 상태 관리|행정 담당자는 등록된 물품의 상태를 `보관 중` 또는 `인도 완료`로 기록하고 변경할 수 있어야 한다. 상태 변경의 권한 및 정정 절차는 정책으로 관리한다.|NEEDS_3, SC3|높음|
|FR_04|문의 방법 안내|사용자는 보관 담당 부서와 문의 방법을 확인할 수 있어야 한다. 개인 휴대전화 번호는 표시하지 않아야 한다.|NEEDS_4, NEEDS_6, SC6, SC8|높음|

## 3. 비기능 요구사항 및 품질 요구사항

|ID|품질 특성|비기능 요구사항|검증 방법/기준|근거|
|---|---|---|---|---|
|NFR_00|개인정보 보호|조회 화면은 개인 휴대전화 번호를 공개해서는 안 된다. 실제 개인정보를 저장·처리하지 않아야 한다.|화면 및 데이터셋 점검에서 개인 전화번호와 실제 개인정보가 없어야 한다.|NEEDS_6, SC8, C_1|
|NFR_01|사용성|분실 학생이 방문 전에 보관 여부, 위치, 문의 방법을 이해할 수 있도록 조회 결과를 명확히 제시해야 한다.|사용자 검토를 통해 세 정보의 확인 가능 여부를 검증한다. 구체적 성공률·시간 목표는 추후 결정한다.|NEEDS_1, NEEDS_4|
|NFR_02|업무 효율성|물품 등록 과정은 행정 담당자의 반복 문의 및 등록 부담을 줄이는 방향으로 설계해야 한다.|현재 등록 소요 시간, 측정 방법 및 개선 목표 수치를 정의한 뒤 전후 비교로 검증한다.|NEEDS_7|
|NFR_03|정확성|조회에 표시되는 보관 상태와 위치는 등록·상태 변경 정보와 일치해야 한다.|등록, 상태 변경 및 조회 시나리오 테스트에서 표시 값의 일치 여부를 확인한다.|NEEDS_1, NEEDS_3|
|NFR_04|운영 적합성|서비스는 가상 데이터로 동작해야 하며, 학교 인증 시스템과 연동하지 않아야 한다.|배포 구성 및 기능 점검에서 실제 인증 연동과 실제 개인정보 사용이 없어야 한다.|C_1|

## 4. 정책

|ID|정책|적용 대상|비고|
|---|---|---|---|
|Pol_00|서비스는 가상 데이터만 사용한다.|전체 서비스|실제 개인정보 및 학교 인증 연동은 제외한다.|
|Pol_01|조회 화면에는 개인 휴대전화 번호를 공개하지 않는다.|조회 및 문의 안내 화면|담당 부서의 공식 문의 방법 안내와 구분한다.|
|Pol_02|분실물 상태는 `보관 중`과 `인도 완료`로 구분한다.|물품 등록·조회·상태 관리|상태 변경 권한과 오류 정정 절차는 추후 확정한다.|
|Pol_03|사진 업로드, 사진 비교·매칭, 자동 알림은 본 버전의 개발 범위에서 제외한다.|전체 서비스|후속 개선 후보로 관리한다.|
|Pol_04|조회에 공개할 정보는 분실물 확인과 방문 전 안내에 필요한 범위로 제한한다.|조회 화면|검색 조건, 공개 항목, 보관 위치의 상세 수준은 정보보호 담당자와 확정한다.|
|Pol_05|습득 학생은 앱에서 습득 물품을 직접 등록하고, 행정 담당자는 분실물 센터로 접수된 습득 물품을 등록한다. 물품 등록의 필수 입력 항목과 그 밖의 역할별 처리 권한은 운영 책임자가 확정한다.|등록 및 상태 관리|등록 주체와 경로는 확정되었으며, 세부 입력·검증 규칙은 추가 확정한다.|
|Pol_06|습득물 인계 장소 안내의 서비스 포함 여부는 기존 안내 체계 확인 후 결정한다.|습득 학생 안내|현재 개발 범위는 미정이다.|
