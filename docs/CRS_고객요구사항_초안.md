# CRS — 과제 관리 프로그램 고객 요구사항서

- 문서 ID: CRS
- 팀명·팀원: 미기재
- 작성일·버전: 2026-10-19 / v0.1
- 상태: 초안, 고객 확인 전
- 요구사항 출처: 사용자 요청(2026-10-19), `SRS_요구사항명세_초안.md` v0.1 초안

> 이 문서는 “사용자가 과제를 적고 마감일과 완료 여부를 확인하는 프로그램”이라는 요청을 요구사항으로 나눈 초안이다. 고객 인터뷰나 별도 답변은 제공되지 않았다. 아래 NEEDS ID는 요청을 추적하기 위해 이 문서에서 나눈 항목이며, 고객이 따로 제시한 원문 ID가 아니다. 팀의 제안은 실제 고객 답변과 구분한다.

## 1. 제품 개요

|항목|내용|
|---|---|
|문제|사용자는 해야 할 과제와 마감일을 기억하고, 각 과제가 끝났는지 확인해야 한다. 현재 요청에는 구체적인 사용 환경이나 기존 관리 방법은 제시되지 않았다.|
|사용자|과제를 등록하고 진행 상황을 확인하려는 프로그램 사용자. 특정 학교·학년·사용자 수는 아직 정해지지 않았다.|
|목표|사용자가 과제를 기록하고, 마감일과 완료 여부를 한곳에서 확인하며, 완료한 과제를 직접 표시할 수 있도록 한다.|

## 2. 개발 범위

|범위 항목|포함·제외·확인 필요|이유와 근거 ID|
|---|---|---|
|과제 내용 등록|포함|사용자가 과제를 적으려는 요청. 구체적인 입력 항목은 Q-01 확인이 필요하다.|
|과제의 마감일 등록 및 확인|포함|사용자가 마감일을 확인하려는 요청. 날짜만 입력할지 시각까지 입력할지는 Q-01 확인이 필요하다.|
|과제 목록과 완료 여부 확인|포함|사용자가 과제와 완료 여부를 확인하려는 요청. 목록의 정렬·필터 기준은 Q-02 확인이 필요하다.|
|과제 완료 표시|포함|완료 여부 확인을 위한 기본 처리로 제안한다. 사용자가 완료 상태를 직접 변경하는 방식은 SRS 초안 UC-03에 반영되어 있으며 Q-03에서 확인한다.|
|등록한 과제 수정|확인 필요|요청에 명시되지 않았고 SRS 초안에도 유스케이스로 정의되지 않았다. 과제 내용이나 마감일이 바뀔 수 있어 Q-04로 확인한다.|
|등록한 과제 삭제|확인 필요|SRS 초안 UC-04에 있으나 사용자 요청에는 명시되지 않았다. 첫 버전에 포함할지 Q-05로 확인한다.|
|앱을 닫은 뒤 과제 데이터 유지|확인 필요|저장 기간과 저장 위치가 정해지지 않았다. 재실행 후에도 유지할지 Q-06으로 확인한다.|
|알림, 캘린더 연동, 여러 사용자 간 공유, 계정·인증|제외 제안|초기 요청에 포함되지 않아 이번 범위에서는 제외하는 안을 제안한다. 필요하면 후속 범위로 논의한다.|

## 3. 고객 요구사항

우선순위는 요청의 핵심 목표에 대한 영향으로 제안했다. 고객이 우선순위를 확정한 것은 아니다.

|CR ID|고객 요구|근거 NEEDS/C/Q ID|포함·제외·확인 필요|우선순위·이유|
|---|---|---|---|---|
|CR-01|사용자는 과제 내용을 프로그램에 등록할 수 있어야 한다.|NEEDS_1|포함|높음 — 과제를 기록하는 핵심 목적이다. 과제명 외에 설명 등 어떤 내용을 입력할지는 Q-01 확인이 필요하다.|
|CR-02|사용자는 과제의 마감일을 등록하고 확인할 수 있어야 한다.|NEEDS_2|포함|높음 — 요청에 직접 포함된 핵심 정보다. 날짜 입력 형식과 선택 입력 허용 여부는 Q-01 확인이 필요하다.|
|CR-03|사용자는 등록한 과제 목록에서 과제별 완료 여부를 확인할 수 있어야 한다.|NEEDS_3|포함|높음 — 요청에 직접 포함된 핵심 목적이다. 완료·미완료 과제를 어떻게 표시하고 정렬할지는 Q-02 확인이 필요하다.|
|CR-04|사용자는 과제가 완료되었을 때 해당 과제를 완료 상태로 표시할 수 있어야 한다.|NEEDS_3, SRS UC-03|포함 제안|높음 — 완료 여부를 최신 상태로 확인하기 위한 처리다. 직접 변경 방식과 완료 상태를 되돌리는 방법은 Q-03 확인이 필요하다.|
|CR-05|사용자는 등록한 과제의 내용을 수정할 수 있어야 한다.|SRS 초안, Q-04|확인 필요|보통 — 입력 오류나 변경 사항을 반영할 수 있도록 포함하는 안을 제안한다. 현재 요청에는 명시되지 않았다.|
|CR-06|사용자는 등록한 과제를 삭제할 수 있어야 한다.|SRS 초안 UC-04, Q-05|확인 필요|낮음 — SRS 초안에 제안된 기능이나, 고객 요청에서 확인되지 않았다. 삭제 기능의 포함 여부를 먼저 합의한다.|
|CR-07|사용자가 저장한 과제는 앱을 닫았다가 다시 열어도 확인할 수 있어야 한다.|Q-06|확인 필요|높음 제안 — 과제 관리 목적을 계속 달성하려면 데이터 유지가 필요할 수 있으나 저장 방식과 기간은 미확정이다.|
