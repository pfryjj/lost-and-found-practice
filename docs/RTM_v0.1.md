# 요구사항 추적표(RTM) v0.1

## 1. 추적 기준

- 추적 방향: 고객 요구사항 → SRS 요구사항·정책
- 상태: `충족`은 SRS에 대응 항목이 있는 경우, `부분 충족`은 핵심은 반영됐으나 세부 기준이 미정인 경우, `미정`은 개발 범위 또는 구현 여부가 결정되지 않은 경우이다.
- 비기능 요구사항은 일반적인 품질 속성만을 별도 요구사항으로 추가하지 않았다. 측정이 필요한 항목에는 아래 표의 정량 목표(초안)를 적용한다.

## 3. 비기능 요구사항 정량 목표(초안)

|ID|연계 고객 요구사항|측정 대상|일반적 목표치(초안)|측정 조건|확정 상태|
|---|---|---|---|---|---|
|01|NEEDS_7 / NFR_02|물품 1건 등록 완료 시간|평균 2분 이내, 기준선 대비 평균 등록 시간 30% 이상 단축|대표 물품 10건 이상을 행정 담당자 또는 대리 사용자로 등록|기준선 측정 후 확정 필요|
|02|NEEDS_1, NEEDS_4 / NFR_01|조회 결과 및 문의 방법 표시 응답 시간|일반 조회의 95%가 3초 이내 완료|가상 데이터와 일반적인 교내 네트워크 환경에서 측정|SRS 추가 반영 필요|

> 참고: `데이터 정확성`처럼 일반적인 품질 속성 명칭만으로는 별도 비기능 요구사항을 추가하지 않았다. 정량화가 가능한 등록 업무 효율성과 조회 성능만 목표치 초안으로 제시했으며, 성능 목표는 현재 SRS v0.1에 명시돼 있지 않으므로 합의 후 비기능 요구사항으로 추가해야 한다.
